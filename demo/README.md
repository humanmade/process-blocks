# Demo content

Demo pages created by `setup.php`, for wp-env and Playground.

| File | Page | Shows |
| --- | --- | --- |
| `sections.html` | `/process-demo/` | A process split into sections |
| `simple.html` | `/process-demo-simple/` | A flat process |
| `ifixit.html` | `/ifixit-screen-replacement/` | A long, real-world guide using Media & Text steps |
