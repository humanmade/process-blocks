Step-by-step process blocks, with a progress checklist and a sticky bar showing the current step.

== Description ==

Add a Process block, then fill it with Steps (or Sections of Steps). Each step has a title and any blocks as content.

On the frontend, readers get:

* A summary checklist of every step, with overall progress and a reset button.
* A sticky bar showing the current step, with a "Mark as complete" button that checks it off and moves to the next.
* Per-step check buttons, to complete steps out of order.

Progress is saved in the reader's browser.
